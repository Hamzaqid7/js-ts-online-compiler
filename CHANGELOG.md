## [1.0.4]

### Features in this release
- JavaScript and TypeScript modes (TypeScript 5.4.5, ES2020 target)
- Custom editor with syntax highlighting, line numbers, auto-closing pairs, auto-indent and comment toggling
- Multi-file tabs for opened `.js` / `.ts` / `.mjs` files
- Sandboxed execution with console capture (`log`, `info`, `warn`, `error`, `debug`, `table`, `clear`)
- `prompt`, `alert` and `confirm` support
- Dark / light theme, adjustable font size, resizable split view
- Built-in examples, open/save file, copy and clear for editor and output
- Animated loader and canvas background (respects reduced-motion)
